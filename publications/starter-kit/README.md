# E7G-T Practical Starter Kit

This directory contains the publication source and reproducible PDF build for the free E7G-T Practical Starter Kit.

## Build

Requirements:

- Python 3
- ReportLab
- DejaVu Sans fonts

Run:

```bash
python3 build_starter_kit.py \
  E7G-T_Practical_Starter_Kit.md \
  E7G-T_Practical_Starter_Kit.pdf
```

The publication is based on the E7G-T v0.10-UC1 unified kernel and is licensed under CC BY-SA 4.0.
