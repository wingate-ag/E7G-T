# Legacy E7G-T Materials

The active project specification is E7G-T v0.10-UC1.

The directory [`release_0.9RC1/`](../release_0.9RC1/) preserves the previous extensional–projective release candidate. Those files are retained for historical comparison, migration testing, and provenance. They must not be cited as the current canonical specification.

The foundations book draft and older release bundles were written before the operational-phase integration. They may contain useful explanations, but their terminology and application logic are not automatically conformant with v0.10.

When reusing legacy material:

1. preserve the historical version label;
2. do not silently replace “context” with “phase”;
3. separate semantic context from inquiry;
4. identify the appropriate typed change;
5. add a phase criterion only when operational equivalence matters;
6. apply the projection-to-phase sufficiency check before relying on a view for classification.
