# APP-001 — AI Output as Projection and Phase Inference

An AI answer is a visible view, not a source. The unified kernel adds a second question:

> Do all admitted source states compatible with the answer support the same reliance phase?

## Example reliance phases

- `draft-only`;
- `plausible-but-unsourced`;
- `source-linked`;
- `currently-verified`;
- `expert-validated-for-use`.

A fluent answer may be compatible with several source states spanning these phases. The answer is not phase-sufficient merely because it is coherent.

## Minimal analysis

```text
View: generated answer
Reconstruction fibre: possible source and support states
Phase criterion: what evidence and validation are required for the intended use
Result: classify only when the relevant source candidates are phase-stable
```

## Required next moves

- one supported phase: use within that phase’s admissible scope;
- several phases: source return, current verification, or another view;
- unknown fibre: abstain or narrow the claim;
- no admitted candidates: repair the model or stop.

## Blocked overreads

- fluency is not evidence;
- citation appearance is not source verification;
- source linkage is not expert validation;
- a correct sentence is not automatically fit for the user’s operational purpose.
